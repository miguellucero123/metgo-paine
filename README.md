# METGO Paine

Clima y **criósfera** en **Torres del Paine** (Patagonia chilena).  
Línea **METGO Glaciares** · SPA Vue 3 + Vuex + Vite · datos Open-Meteo.

> Antes: portafolio académico *ClimaTorre* / `portafolio-modulo7`.  
> Producto: **METGO Paine** (Netlify: `metgo-paine`).

## Local

```bash
npm install
npm run dev
```

## Build / Netlify

```bash
npm run build
```

Publish: `dist` (ver `netlify.toml`).
